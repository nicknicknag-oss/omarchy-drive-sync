Omarchy Drive Sync

A personal Google Drive integration operated by nicknicknag-oss on their own computers, using rclone and the Omarchy Google Drive plugin.

Purpose

The desktop integration can synchronize selected Drive folders with local files and optionally provide a read-only browse mount. A planned use is transferring separate backup snapshots of Codex session history; this does not imply automatic import into Codex or synchronization of its live data directory.

Google access

The desktop application requests Google Drive access to list, read, upload, update and delete files as needed for selected two-way synchronization. OAuth authorization is handled by Google and rclone. Two-way synchronization can propagate deletions.

This website is informational. It has no Google sign-in, receives no OAuth tokens and does not store Drive files.
